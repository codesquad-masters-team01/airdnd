# AirDnD 프론트엔드

AirDnD를 위한 React/Vite 클라이언트입니다.

## 예정 기술 스택

- React
- Vite
- JavaScript
- React Router
- Fetch API
- CSS 방식은 팀에서 선택

## 초기 화면

- 메인 숙소 목록
- 숙소 상세
- 로그인
- 예약 목록/확인
- 마이페이지
- 호스트 숙소 관리

## 환경 변수

```text
VITE_API_BASE_URL=http://localhost:8080
```

## 디자인 자료

제공된 SVG 참고 자료는 `design/SVG`에 있습니다.
